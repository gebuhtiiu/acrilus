# Worksheets — Grades 1–3

## Worksheet 1 — File sorting
Match each file to the right folder: Pictures, School Work, Projects.

## Worksheet 2 — Better file names
Rename:
- `file1.jpg`
- `doc2.doc`

## Worksheet 3 — Private or safe?
Circle whether each item is private or safe to share:
- home address
- favorite color
- password
- favorite game

## Worksheet 4 — Password practice
Create a fake practice password using `Animal + Number + Symbol`.

**Important:** Students should never write a real password here.
