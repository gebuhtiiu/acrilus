# Digital Life Skills for Grades 1–3

## Learning objectives

Students should be able to:
- explain what digital files are
- sort files into simple folders
- choose clearer file names
- recognize personal information
- understand that passwords should stay private
- practice basic device care

## Module 1 — What is digital stuff?
Examples: pictures, homework, videos, stories.

## Module 2 — Organizing files
Folders work like containers for different kinds of digital things.

## Module 3 — Naming files clearly
Bad names: `file1`, `stuff`, `document`.
Good names: `Math Homework Week 2`, `Birthday Party Photo`.

## Module 4 — Personal information and privacy
Teach which information should stay private and when to ask a trusted adult.

## Module 5 — Password basics
Passwords are secret keys. Never put real passwords on class worksheets.

## Module 6 — Taking care of devices
Keep devices clean, don’t drop them, save work, and log out when finished.
