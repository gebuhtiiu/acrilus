# Product Roadmap

## Phase 1 — Framework Publication
Publish standards, guides, templates, research, and curriculum.

## Phase 2 — Security and Education Library
Expand the public library with identity architecture, credential design, worksheets, and K–12 materials.

## Phase 3 — Product Definition
Finalize the product vision, MVP scope, architecture, and schema.

## Phase 4 — Reference Implementation
Build the first working metadata-layer prototype.

## Phase 5 — Future Platform
Expand into stronger automation, indexing, and resilience features.
