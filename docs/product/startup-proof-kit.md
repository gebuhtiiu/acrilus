# Startup Proof Kit

## Purpose

This document lists the minimum artifacts required to make Acrilus look like a legitimate early-stage product initiative to startup programs, partners, or profile reviewers.

## Minimum set

- domain + founder address
- public landing page
- public GitHub repo
- README and roadmap
- product vision
- MVP PRD
- one or two diagrams
- a few issues and milestones
- small prototype code scaffold

## Strongest signals

1. architecture diagrams
2. polished landing page
3. roadmap
4. product requirements document
5. public repository structure

## Suggested one-line description

Acrilus is building a metadata-driven personal information management platform grounded in digital organization standards, identity architecture, and long-term digital resilience.
