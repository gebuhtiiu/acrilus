# Personal Digital Life Map

## Purpose

The Personal Digital Life Map visualizes the interacting layers that make up an individual’s digital environment so dependencies become visible rather than hidden.

## Layers

1. Personal Identity
2. Account Layer
3. Credential Layer
4. Device Layer
5. Data Layer
6. Backup Layer

## Why it matters

Mapping these layers helps a person identify:
- critical dependencies
- hidden single points of failure
- risky recovery chains
- unprotected data stores
- over-concentrated identities

## Practical use

Create a personal map listing identities, major accounts, credentials, devices, data stores, and backups. Then trace how recovery actually works if the primary phone, email, or computer is lost.
