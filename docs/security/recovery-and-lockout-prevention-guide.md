# Recovery and Lockout Prevention Guide

## Purpose

Many digital failures are not direct hacks but loss of access: lost devices, dead phone numbers, stale recovery addresses, or missing backup codes.

## Recovery design questions

For each critical account, document:
- primary login identifier
- password location/method
- second factor
- recovery email
- recovery phone
- backup code location
- fallback if the phone is lost
- fallback if the primary email is inaccessible

## Principle

A secure account that cannot be recovered is still a failure mode.

## Practice recommendation

Run a recovery-path audit at least once per year and perform a live recovery drill on a low-risk account to verify the process still works.
