# Device Security Baseline

## Purpose

Devices are the physical access layer of a digital system. They should have defined roles and minimum protections.

## Baseline controls

- strong lock method
- encryption enabled
- automatic updates
- backup configured
- browser/profile separation where needed
- remote wipe where supported
- least-privilege app permissions

## Device categories

- primary phone
- primary computer
- backup computer/device
- portable storage
- long-term backup media

## Principle

Not every device should do everything. Role clarity improves security and recoverability.
