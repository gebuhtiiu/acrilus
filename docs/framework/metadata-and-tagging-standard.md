# Metadata and Tagging Standard

## Purpose

Folders provide primary structure. Metadata provides flexible retrieval.

## Recommended metadata fields

- Category
- Entity
- Document Type
- Date
- Status
- Lifecycle State
- Tags

## Why metadata matters

Metadata supports retrieval patterns that folders alone do not handle well, such as:

- all invoices from a specific vendor
- all files related to a vehicle
- all medical records within a date range
- all items with unresolved follow-up

## Controlled vocabulary

To remain useful, metadata should use consistent values rather than uncontrolled synonyms.

Example document types:
- Invoice
- Receipt
- Statement
- Contract
- Manual
- Report
- Policy
- Medical Record

## Tagging principles

- Tags should be optional but intentional.
- Use tags for cross-cutting concepts, not as a substitute for structure.
- Review tag sprawl periodically.
