# Personal Information Governance Guide

## Purpose

Governance defines how information should be retained, protected, reviewed, and disposed of over time.

## Key concepts

### Ownership
Each important information domain should have a clear owner or maintenance responsibility.

### Retention
Not every file should be kept forever. Retention policy prevents uncontrolled growth.

### Data minimization
Sensitive information should be retained only when it has ongoing value.

### Accountability
Systems should be reviewed periodically to confirm they still reflect reality.

## Example retention ideas

- Tax documents: retain according to legal and practical need
- Medical history: often permanent
- Warranty receipts: until warranty expiration plus buffer
- Temporary downloads: short-lived unless incorporated into recordkeeping
