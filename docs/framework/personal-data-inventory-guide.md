# Personal Data Inventory Guide

## Purpose

A data inventory helps a user understand what systems they depend on, what information each holds, and how resilient each location is.

## Recommended fields

- System
- Data Type
- Location
- Backup Status
- Retention
- Sensitivity
- Owner / Account

## Example entry

- System: Google Drive
- Data Type: Financial records
- Location: Financial/Reference
- Backup Status: Local SSD + secondary cloud copy
- Retention: Permanent
- Sensitivity: High

## Why it matters

Inventories expose hidden dependencies, missing backups, and over-concentrated risk.
