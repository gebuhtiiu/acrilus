# Digital Hygiene Maintenance Guide

## Purpose

A good system requires maintenance. Digital hygiene keeps a structured environment from decaying into clutter.

## Monthly tasks

- review Inbox folders
- rename and categorize newly captured files
- remove obvious duplicates
- review downloads and desktop clutter

## Quarterly tasks

- verify backups
- review archive growth
- standardize inconsistent names or tags
- close out stale Current items

## Yearly tasks

- storage audit
- retention review
- backup restoration test
- taxonomy refresh if needed

## Principle

Maintenance should be light, regular, and predictable rather than rare and overwhelming.
