# File Naming Standard

## Purpose

A filename should communicate enough information to identify a document without opening it.

## Standard pattern

`Type - Subject - Entity - Date.ext`

## Components

### Type
High-level document class.

Examples: Invoice, Receipt, Statement, Contract, Manual, Medical Record, Report

### Subject
The specific matter the file concerns.

Examples: Internet Service, Blood Test, Vehicle Registration, Lease Renewal

### Entity
The organization, vendor, provider, or person associated with the file.

Examples: Comcast, Quest Diagnostics, Honda, State Farm

### Date
Use ISO-style formatting for natural sorting.

Examples:
- `2026`
- `2026-03`
- `2026-03-15`

## Examples

- `Invoice - Internet Service - Comcast - 2026-03.pdf`
- `Medical Record - Lab Results - Quest Diagnostics - 2025-11-08.pdf`
- `Manual - Appliance - Samsung Washer WA51A5505AW - 2023.pdf`

## Rules

- Prefer full words unless a standard abbreviation materially improves clarity.
- Use the same separator pattern consistently.
- Make dates sortable.
- Avoid vague names such as `scan1`, `document`, or `final-final`.
- Rename files during processing rather than leaving downloads with their original names indefinitely.
